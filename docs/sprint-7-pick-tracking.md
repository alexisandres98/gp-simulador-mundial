# Sprint 7 — Seguimiento de picks

Política oficial **`flat_1_unit_v1`**. NO significa que GP ejecutó la apuesta. Cada pick registra `tracking_stake_units=1`, `tracking_policy=flat_1_unit_v1`, `executed_by_gp=false`.
Resultado teórico tras settlement: win → `odds−1` unidades; loss → `−1`; void → `0`. Siempre etiquetado **"RETORNO TEÓRICO CON STAKE UNITARIO — NO REPRESENTA OPERACIONES REALIZADAS"**. No bankroll real, no % de patrimonio.
